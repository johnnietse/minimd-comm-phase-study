RECOMMENDATIONS FOR IMPROVED MONITORING:
================================================================================

1. For low MPI ranks (≤4):
   - Focus on per-rank metrics, not node-level metrics
   - Use power-per-rank and CPU-per-rank for classification
   - Ignore node idle percentage (always misleading)

2. For medium MPI ranks (5-16):
   - Combine per-rank and node-level metrics
   - Use network activity as secondary indicator
   - Monitor synchronization patterns

3. For high MPI ranks (≥17):
   - Node-level metrics become more reliable
   - Network bandwidth is a strong indicator
   - Context switches correlate with communication

4. Always:
   - Normalize metrics by rank count
   - Use empirical scaling data for calibration
   - Consider the percentage of idle cores in calculations
